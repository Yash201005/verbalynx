# VerbaLynx Data Sources

VerbaLynx uses external linguistic datasets for language-learning content.

## Tatoeba

Used for multilingual example sentences.

Website:
https://tatoeba.org/

The imported sentence data is subject to the applicable Tatoeba licensing terms.
